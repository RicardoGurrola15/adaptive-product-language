# Tone and register

Tone is the emotional stance; register is the level of formality and vocabulary. Declare both separately from language and locale.

## Default product register

Use plain, concrete, respectful language. Prefer active verbs, short sentences, specific outcomes, and a calm acknowledgment of user effort. Match the seriousness of the state: neutral for routine actions, supportive for errors, factual for pricing, and restrained for marketing.

## Context matrix

| Context | Tone | Register | Avoid |
|---|---|---|---|
| Onboarding | Welcoming, orienting | Plain, encouraging | Hype, assumptions about expertise |
| Form help | Clear, patient | Direct, instructional | Jargon and redundant explanations |
| Validation error | Respectful, recovery-focused | Specific, concise | Blame and vague failure |
| Destructive action | Candid, deliberate | Unambiguous | Euphemism or accidental consent |
| Pricing/paywall | Factual, transparent | Plain commercial | Pressure, hidden terms, inflated claims |
| Success | Confirming, restrained | Brief | Overpromising or forced celebration |
| Empty state | Helpful, motivating | Action-oriented | Blaming the user |
| System outage | Honest, calm | Operational | Fake certainty or technical dumping |

## Adaptation rules

- Keep tone consistent across a flow, but let state severity change the wording.
- Use the requested brand voice only when it does not conflict with truth, accessibility, or informed choice.
- Do not use regional slang unless explicitly requested for the artifact.
- For Spanish, use neutral professional wording appropriate to the selected locale.
- For English, distinguish en-US and en-GB spelling and product conventions without caricature.
